# AI Complaint Analyzer

An AI-inspired web application that analyzes customer complaints, identifies their category and sentiment, estimates urgency, and helps users track complaint status.

## Features

- Customer registration and login interface
- Complaint categorization
- Sentiment analysis: Positive, Neutral, or Negative
- Urgency and priority estimation
- Complaint ticket tracking
- Dashboard with complaint status summaries
- Smart routing based on the complaint or service provider

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- JSON file storage

## Run Locally

1. Install [Node.js](https://nodejs.org/).
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Install dependencies:

   `npm install`

5. Start the server:

   `node server.js`

6. Open `http://localhost:3000/login.html` in your browser.

## Project Status

This is a learning project and prototype. Complaint classification uses rule-based logic, and external service routing may be simulated rather than connected to official company APIs.
